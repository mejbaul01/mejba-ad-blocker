# Mejba Ad Blocker

A free, open-source ad blocker for Chrome, Edge, Brave and other Chromium browsers.
Made by SMT Company.

## Features
- Blocks ads from 44,000+ ad-server domains (EasyList based)
- Hides cookie pop-ups, newsletter/sign-up overlays and floating videos
- Skips YouTube ads (best effort, YouTube changes often)
- Turn blocking on or off for all sites, or for one site only
- Add your own domains to block
- No tracking, no account, no data collection. Everything stays in your browser.

## Install (Chrome / Edge / Brave)
1. Download `mejba-ad-blocker.zip` from the **Releases** page and unzip it.
2. Open `chrome://extensions` (Edge: `edge://extensions`).
3. Turn on **Developer mode**.
4. Click **Load unpacked** and select the unzipped `mejba-ad-blocker` folder.
5. Pin the extension from the puzzle icon.

Do not drag and drop the zip into Chrome. Use **Load unpacked** with the folder.

## Update
Download the new zip, remove the old extension, and load the new folder again.

## Report a problem
Open an Issue on GitHub. Please include the website link and what ad you still see.

## Privacy
Mejba Ad Blocker does not collect, store or send any personal data. Settings are saved only
in your own browser.
